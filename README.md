# Python-Data-Structures-Strings-and-Tuples

## Overview
The repository covers Python strings and tuples through simple coding exercises

## Topics Covered
-**Strings:** 
Creation, concatenation, indexing, slicing and string methods such as upper(), lower(), capitalize(), count(), and replace()
-**Tuples:** 
Creation, accessing, elements, concatenation, repetition, and slicing

## Tools & Technologies
- Python
- Jupyter Notebook

## Objective
To understand string operations and tuple manipulation in Python.
